Employee Management SystemУчебный проект, демонстрирующий применение принципов объектно-ориентированного программирования на Java:наследование, полиморфизм, инкапсуляцию, абстрактные классы, интерфейсы и паттерн проектирования Builder.
Проект выполнен в учебных целях. Конструктивная критика и предложения приветствуются.

Структура проекта
src/
└── lesson1/
    ├── Employee.java        # Абстрактный базовый класс
    ├── Developer.java       # Класс разработчика
    ├── Manager.java         # Класс менеджера
    ├── Intern.java          # Класс интерна
    ├── Workable.java        # Интерфейс отвечающий за рабочее поведение
    ├── Reportable.java      # Интерфейс отвечающий за генерацию отчета по сторудникам
    └── Main.java            # Точка входа
    

 Для создания объекта используется Builder с цепочкой вызовов:

Обязательные поля
id (передаётся в конструктор Builder)
firstName
lastName
email

Опциональные поля
position
department
salary
